# Study

Windows 端的学习计划应用，使用 Flutter 构建。六个学科入口按语数英物化生排列，当前开放数学。

应用只负责安排学习计划：学生自己决定每次学多少知识点，应用告诉学生学哪些，并在学习完成后按固定节奏安排复习。

## 当前功能

- 语文、数学、英语、物理、化学、生物六个学科入口
- 数学内置 41 个知识点，按 8 个章节排列
- 每次学习数量由学生自己选择
- 学习完成后自动安排第 1、3、7、15、30 天的复习
- 到期的复习按日期列出，完成一个就勾选一个
- 章节进度、未来 7 天复习安排、今日新学与复习数量、连续学习天数
- 学习记录保存在本机 SQLite，支持清空进度
- 浅色、深色和跟随系统三种主题

当前版本不提供知识点讲解或答题辅助，只提供计划与记录。其余五个学科显示为准备中。

## 使用方式

1. 进入数学页面，选择今天要学几个知识点。
2. 点击「开始学习」，按顺序学习列出的知识点，学完一个就勾选一个。
3. 点击「完成学习」，这些知识点会自动进入复习计划。
4. 到期后进入「复习」，复习完知识点后在列表里勾选完成。

## 复习规则

- 每个知识点在学习后的第 1、3、7、15、30 天各复习一次。
- 复习时间按学习日期固定计算，不根据掌握程度调整。
- 错过的复习会保留在列表中，显示为逾期。
- 同一个知识点每天最多完成一次复习。
- 完成第 5 次复习后，该知识点标记为已完成。

## 开发

需要 Flutter 3.41 或更高版本，以及 Visual Studio 的 C++ 桌面开发组件。

```bash
flutter pub get
flutter run -d windows
```

运行测试：

```bash
flutter test
```

构建发布版本：

```bash
flutter build windows --release
```

生成的应用位于 `build/windows/x64/runner/Release/`。

## 数据

学习数据保存在 `%APPDATA%\Study\study.db`，通过 Windows 自带的 `winsqlite3.dll` 访问。设置页可以查看数据文件路径，也可以清空全部学习进度。
