# Study

Windows 端的学习计划应用，使用 Flutter 构建。六个学科按语数英物化生排列，全部可以独立使用。

应用只负责安排学习计划：学习者自己添加知识点、决定每次学多少，应用列出要学的内容，并在学习完成后按固定节奏安排复习。

## 专注模式

启动后先选择学科。进入某个学科后，界面只显示这个学科，不提供侧边栏或其他学科入口。

要切换学科，必须点击「切换学科」并确认退出，回到学科选择页重新进入。学习和复习过程中不能切换学科。

## 当前功能

- 语文、数学、英语、物理、化学、生物六个独立学科
- 不内置知识点，由使用者按章节自行添加
- 知识点可以编辑和删除，删除时一并清除学习记录
- 每次学习数量由学习者自己选择
- 学习完成后自动安排第 1、3、7、15、30 天的复习
- 到期的复习按日期列出，完成一个就勾选一个
- 章节进度、未来 7 天复习安排、今日新学与复习数量、连续学习天数
- 顶部进度条在勾选时平滑变化
- 设置入口在右上角
- 浅色、深色和跟随系统三种主题

## 使用方式

1. 在学科选择页进入一个学科。
2. 首次进入时打开「管理知识点」，按章节添加要学习的内容。
3. 在学科主页选择今天要学几个知识点，点击「开始学习」。
4. 按顺序学习列出的知识点，学完一个就勾选一个，然后点击「完成学习」。
5. 到期后进入「复习」，复习完知识点后在列表里勾选完成。

## 复习规则

- 每个知识点在学习后的第 1、3、7、15、30 天各复习一次。
- 复习时间按学习日期固定计算，不根据掌握程度调整。
- 错过的复习会保留在列表中，显示为逾期。
- 同一个知识点每天最多完成一次复习。
- 完成第 5 次复习后，该知识点标记为已完成。

## 开发

需要 Flutter 3.41 或更高版本，以及 Visual Studio 的 C++ 桌面开发组件。

```bash
flutter pub get
flutter run -d windows
```

运行测试：

```bash
flutter test
```

构建发布版本：

```bash
flutter build windows --release
```

生成的应用位于 `build/windows/x64/runner/Release/`。

## 数据

学习数据保存在 `%APPDATA%\Study\study.db`，通过 Windows 自带的 `winsqlite3.dll` 访问。设置页可以查看数据文件路径，也可以清空全部学习进度并保留知识点。
